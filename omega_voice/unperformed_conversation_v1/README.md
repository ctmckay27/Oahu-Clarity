# MARI_UNPERFORMED_CONVERSATION_v1

Purpose: remove explicit acting from Mari's current coherent native voice path without changing the selected Mari Voice v1 / G1-1 acoustic identity.

## Core law

Internal state does not earn an acoustic consequence merely by existing.

The path is:

listener turn
  -> Mari conversational action
  -> utterance formation / lexical structure
  -> audibility gate
  -> one-session native Mari renderer

The audibility gate admits ordinary wording, questions, repairs, and revisions as actual conversational structure, but it does not translate categorical thoughts such as searching, correcting, realizing, irritation, familiarity, or relationship state into hand-authored rate, pause, emphasis, finality, volume, or trajectory recipes.

## v1 behavior

Preserved:
- selected Mari Voice v1 / G1-1 x-vector profile
- one decoder session / one model invocation
- source-bound non-starving text release
- actual response wording and clause structure
- explicit lexical corrections and revisions already present in the utterance
- turn continuity and source-consumption audit

Suppressed:
- categorical thought -> acoustic trajectory
- thought -> onset actuation
- relationship -> acoustic projection
- manual prominence/finality/rate/volume recipes
- arbitrary pause insertion
- random disfluency / fake breath / fry / noise
- prose acting instructions

The underlying native continuity plan remains verifiable, but its injected trajectory weights and onset are exactly zero.

## Evidence boundary

This is deliberately subtractive. It does not claim that zero explicit actuation is final. It asks a narrower question:

Does Mari become more conversational when the coherent carrier is allowed to speak without being directed to perform its internal state?

Any acoustic control added after v1 must be justified by a specific conversational event that cannot survive through wording/structure/native generation alone.
