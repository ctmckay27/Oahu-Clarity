# MARI_NATIVE_PROSODY_BASIS_v1

Goal: expand Mari's identity-safe native acoustic control space without returning
to acting presets or cross-speaker performance transfer.

Candidate basis:
- finality / continuation: pre-existing measured same-speaker axis
- onset pressure: same-Mari firm/soft calibration
- speaking tempo: same-Mari fast/slow time-scale calibration
- local semantic focus: same-Mari local pitch/level prominence calibration

A candidate is not admitted because its calibration reference exists. It must
reproduce its intended consequence in held-out **free generation** while
preserving the selected Mari profile, intelligibility, and speaker similarity.

Calibration stimuli are diagnostic counterfactuals, never voice assets.
